Composed Recipe · Create / edit form flow · one skin, five compositions

Same skin. Five ways to fill in a form.

One job — create or edit a “Product” record (name, category, price, description, visibility) — composed five ways. Every frame wears the same neutral skin: off-white page, white surfaces with hairline borders, slightly-rounded corners, one restrained blue accent, system sans with tabular figures. What changes is purely composition and interaction.

Composition 1
Single-column form

PULLS — a classic vertical form in sections (top labels, helper text, mixed field types incl. a select and a toggle with a visible thumb) + a sticky bottom action bar (Save / Cancel).  WHY — the most reliable default: one column means one clear path down the page, and a sticky bar keeps the commit action in reach however long the form runs.

Composition 3
Multi-step wizard

PULLS — a horizontal stepper (Details → Options → Review) with the current step's fields + Back / Next.  WHY — for longer or branching creation: chunking the form into ordered steps reduces overwhelm and lets each step validate before the next.

Composition 4
Inline-edit record

PULLS — a record/detail view where fields are inline-editable (pencil affordance, edit-in-place, with a save bar that appears on change).  WHY — for editing existing records: showing the saved values as readable text and letting users edit a single field in place is faster and less destructive than a full form.

Composition 5
Validation errors

PULLS — the form showing validation: error-styled fields with messages + an error summary at the top, plus one valid field for contrast.  WHY — recovering from mistakes is a core state: a summary that lists and links errors, with each field marked and explained inline, gets users to a fixable path fast.

Skins & how to apply them

A skin is the full set of visual tokens — color, type, radius, elevation, and density — applied uniformly. Pick ONE skin per product and apply it across whichever compositions you choose: the composition is the skeleton, the skin is the paint, so any composition above renders coherently in any skin. Every frame on this page uses the Neutral column.
