Lists & selection

For lists too long for a Select #lists-selection

Three primitives the system has been quietly assuming. Combobox covers long single-select lists; MultiCombobox covers multi-select; OverflowScroll wraps rows / tile strips that need to scroll inside a fixed container. Pick the right one and the page stops growing scrollbars and stale "Select" controls.

Selectsmall, bounded set
Use for regions, statuses, year ranges — anything that fits on one screen and never grows.
Avoid when the list could ever exceed ~30 items, or when the answer is "we'll keep adding to it."
Comboboxlong or growing single-select
Use when the list grows over time — users, vehicles, businesses, officers. Search-filter on a popover list.
Avoid shipping client-side filtering against page_size: 100 — paginate properly (see server-search mode).
MultiComboboxmulti-select with chips
Use when users need several from a list — tags, attendees, recipients. Chips render inside the field.
Avoid for binary state (use checkboxes) or for < 6 options on one screen (use a checkbox group).
OverflowScrollcapped lists · tile strips
Use for horizontal tile strips and capped-height lists in cards. Press-and-hold arrows + fading edges.
Avoid raw overflow:auto — the user can't see there's more, and the scroll-thumb pops in late.

Combobox #combobox

Single-select picker for long or growing lists. Text input filters an option list in a popover. The trigger reuses .input + .input-affix; the panel reuses .menu. Three reserved row types: loading, empty, error.

Loading row pins to the top while a 300 ms debounced request is in flight; previous results stay visible at reduced opacity. Empty and error rows replace the list entirely.
Anatomy

.input + .input-affix (trigger) → .combobox-popover (panel reusing .menu tokens) → reserved rows: .combobox-row--loading, .combobox-row--empty, .combobox-row--error. Substring match: .combobox-match. Selected check: .combobox-check.

Server-search rule

Backend-paginated lists must use server-side search (300 ms debounce + a seen-map keyed by id, so the selected row keeps its label after it scrolls out of the current batch). Don't ship client-side filter over page_size: 100 as a shortcut.

14 — Multi-combobox

Multi-combobox #multicombo

Same family as Combobox — multi-select. Selected values render as removable chips inside the field; search input flows after the chips and stays put across opens so you can keep picking. Same loading / empty / error rows; same seen-map rule for server-paginated lists.
