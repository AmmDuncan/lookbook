06 — Content shell

Content shell #content-shell

Three shapes a page can take. Same atoms, very different feel — choose the shape that matches the reading job.

(a) Centered narrow use when: long-form content · docs · articles

Docs Components Buttons
Components

Buttons

Use buttons to trigger an action. They come in five variants and five sizes; pick the variant that matches the importance of the action, and the size that matches the surface.

Variants

Primary buttons are reserved for the single action you want the user to take on a screen. Everything else steps down through secondary, ghost, and link — never two primaries on one screen.

Sizes

Five sizes anchored to the shared scale. btn--md is the default for desktop; tap devices auto-promote it to 44 px.

Centered ~640 px column. Best for prose: docs, blogs, walkthroughs.
