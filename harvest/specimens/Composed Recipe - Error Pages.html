Composed Recipe · Error pages · one skin, five compositions

Same skin. Five ways things go wrong.

The pages users hit when something fails — composed five ways. Every frame wears the same neutral skin: off-white page, white surfaces with hairline borders, slightly-rounded corners, one restrained blue accent, system sans with tabular figures. Visuals stay quiet — a large status number or a single line glyph, never illustration. What changes is purely composition and interaction.

Composition 1
404 — Not found

PULLS — a big quiet “404” + “page not found” message + a search box + primary “Back home” + a few helpful links.  WHY — the most common error: a recognizable number reassures it's just a dead URL, and search plus shortcuts give a way forward instead of a wall.

404

This page can't be found

The page you're looking for may have been moved, renamed, or never existed. Try a search or head back home.

Composition 2
403 — Forbidden

PULLS — a lock line-glyph + “you don't have access” + a request-access CTA + a “switch account” secondary; calm, not alarming.  WHY — access denials shouldn't feel like a crash: a calm lock and a clear request path treat it as a permissions gap to resolve, not a failure.

You don't have access to this page

This workspace is restricted. Ask an admin for access, or switch to an account that has permission.

Reference · 403 · workspace/northwind
Composition 3
500 — Server error

PULLS — “something went wrong” + a collapsible technical detail (error id / timestamp, mono) + Retry + Report buttons.  WHY — for unexpected failures: a plain apology serves most users, while a tucked-away detail block gives the ID support actually needs without alarming anyone.

Something went wrong on our end

Composition 4
Maintenance

PULLS — a scheduled-maintenance state: status message + estimated-back-by time + a subtle status pill (chip hugs content) + a status-page link.  WHY — planned downtime is reassuring when it's framed as planned: an ETA and a live status pill tell users it's temporary and tracked, not broken.

Scheduled maintenance

We'll be back shortly

Harbor is undergoing scheduled maintenance to ship some improvements. Your data is safe and nothing is lost.

Estimated back by 09:30 UTC · about 25 minutes
View status page
Composition 5
Offline / connection lost

PULLS — an offline glyph + “you're offline” + an auto-retry indicator (a small spinner / countdown) + a manual Retry.  WHY — connectivity loss is usually transient: an auto-retry countdown does the waiting for the user, while a manual button respects those who'd rather not wait.

You're offline

We can't reach the network right now. We'll keep trying automatically — your work will sync once you're back.

Reconnecting in 5s…

Skins & how to apply them

A skin is the full set of visual tokens — color, type, radius, elevation, and density — applied uniformly. Pick ONE skin per product and apply it across whichever compositions you choose: the composition is the skeleton, the skin is the paint, so any composition above renders coherently in any skin. Every frame on this page uses the Neutral column.
