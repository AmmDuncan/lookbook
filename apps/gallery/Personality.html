02 — Illustration · iconography

Illustration & icon style #illustration

Define stroke weight, corner radius, and composition language. Stay geometric — circles, squares, rounded rects, hairlines. No mascots, no hand-drawn squiggles, no clip-art.

Reskinnable surface

Values you can change per project without touching a component:

--accent · --accent-hover · --accent-subtle --bg · --surface · --surface-sunken · --surface-raised --border · --border-strong --text-primary · --text-secondary · --text-muted --radius-{sm,md,lg,xl} --shadow-{sm,md,lg,xl} --font-sans · --font-mono --accent-secondary · --accent-gradient (marketing only)

Structural constants

Names and shapes that stay identical across projects so components keep working:

--space-* · 4 px base · do not retune --size-{xs,sm,md,lg,xl}-h · control heights --bp-{sm,md,lg,xl,2xl} · breakpoints --z-{base,dropdown,sticky,overlay,modal,toast} --duration-* · --ease-* · motion grammar Semantic role NAMES (--text-primary, --border, etc.) Component class names (.btn, .input, .card, etc.)
Change the values, keep the names. A new project ships a new tokens.css with different left-column values; every component reads through the right-column structural constants and just works.

How to apply a preset

Copy the override block (the inline style="--accent: …" on each card above) into :root in your own tokens.css. Components don't change — only the values do. The full contract stays intact: every component still reads var(--accent), var(--radius-md), etc.
