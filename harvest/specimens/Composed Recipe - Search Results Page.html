Composed Recipe · Search / results page · one skin, five compositions

Same skin. Five ways to return a search.

One query — “renewal” across a workspace — answered five ways. Every frame wears the same neutral skin: off-white page, white cards with hairline borders, slightly-rounded corners, one restrained blue accent, system sans with tabular figures. What changes is purely composition and interaction: how results are grouped, filtered, previewed, or invoked. The skin is the paint, the composition is the skeleton.

Composition 1
Results list + facets

PULLS — top search bar (active query + result count) + left facet rail (type checkboxes, date, tags) + central result rows (title + snippet + meta + source) + numbered pagination.  WHY — the classic web-search layout: facets let users narrow a large, mixed result set, and ranked rows with snippets are the fastest way to judge relevance.

Composition 2
Federated / grouped

PULLS — one unified search bar + results grouped by type (People / Files / Projects) each as a labeled section with a few items and a “See all (N)” link.  WHY — for multi-entity search across a product: grouping by type lets the user jump straight to the kind of thing they meant, without choosing a scope up front.

Composition 3
Search + preview pane

PULLS — results list on the left + a preview pane on the right showing the selected result's detail.  WHY — the email/file-search pattern: when results are dense and inspectable, previewing in place lets users triage many hits without opening each one in full.

Composition 4
Command palette

PULLS — a centered ⌘K palette over a dimmed page: input with keyboard hints + instant results grouped into Recent / Suggested / Actions, one row highlighted with ↑↓ and ↵ hints.  WHY — for power users: search becomes a launcher, mixing navigation and actions so the keyboard alone gets you anywhere in the product fast.

Composition 5
Zero-results

PULLS — the empty no-results state: the query shown, a “no matches” message, a did-you-mean suggestion, and a short list of popular/recent searches as chips.  WHY — a dead end is the riskiest moment in search; spelling rescue plus popular queries turn “nothing found” into an obvious next move.

Skins & how to apply them

A skin is the full set of visual tokens — not just color and font, but radius, elevation, and density too — applied uniformly. Pick ONE skin per product and apply it across whichever compositions you choose: the composition is the skeleton, the skin is the paint, so any composition above renders coherently in any skin. Every frame on this page uses the Neutral column.
