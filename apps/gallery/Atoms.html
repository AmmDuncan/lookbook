01 — Typography in practice

Typography #typography

Specimen-on-content. Same scale as Foundations, applied to a realistic article shell.

Engineering

Designing a token-first component library.

A coherent system starts at the smallest unit. When every button, input, and badge reads from the same set of variables, swapping the skin doesn't break the silhouette.

Why the token names matter

Components reference roles, not literals. --accent can be cobalt today and ochre tomorrow; the button still knows where to put its color, and the underline still knows where to land.

Dense UI copy lives at 14 px. Helpers and meta drop to 13 and 12 — never smaller in product surfaces.

02 — Size scale

Size scale #sizes

One scale, five steps, height-anchored. button-md, input-md, select-md, and stepper-md share the same height — drop them in a row and they line up. On coarse-pointer devices, md auto-promotes to lg values so the default control clears the 44 px AAA tap target without any code change.

Scale tokens --size-{xs,sm,md,lg,xl}-*

Desktop values. On coarse pointers md aliases lg — 36 → 44 — so every default control passes the WCAG 2.5.5 AAA 44 px tap target.
