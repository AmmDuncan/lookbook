Inline create from a picker: where each container shines

A · Accordion below shines when the host form can grow: the picker never moves, the form takes NEW space under it, and the confirmation lands where the eye already is. Default.

B · Replace in place shines when height is the constraint (drawer, slideover, short card): the slot swaps, total height stays near constant. Crossfade must be sequenced, exit before enter.

C · Inside the popover shines for a one-field, instant create (add a tag, press Enter). With a real form it covers the fields it exists to unblock and Tab lands behind it. Its list-to-form slide is the clearest “one level deeper” cue and can live inside A's panel.
