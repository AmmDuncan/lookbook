Composed Recipe · Empty / first-run states · one skin, five compositions

Same skin. Five kinds of nothing.

The states that greet a user when there's nothing to show — composed five ways. Every frame wears the same neutral skin: off-white page, white surfaces with hairline borders, slightly-rounded corners, one restrained blue accent, system sans. Illustrations stay minimal — a single line glyph on a soft disc, never fake imagery. What changes is purely composition and interaction.

Composition 1
First-run welcome

PULLS — a full-surface welcome for a brand-new account: short headline + supporting line + primary CTA + a quiet secondary link.  WHY — the very first screen sets the tone: one centered message and a single clear action beat a dashboard full of zeros for getting someone started.

Composition 3
Filtered to zero

PULLS — a list with active filter chips applied that match nothing: a “no matches” message + “Clear filters” CTA — distinct from a true no-data state.  WHY — the data exists; the query is just too narrow. Echoing the active filters and offering to clear them points at the real cause instead of implying the list is empty.

Composition 4
Connect a source

PULLS — an empty dashboard prompting setup: 3 connect-cards (data source / integration / import) each with a Connect button, plus a skip link.  WHY — a dashboard with no data is blocked on one thing — input. Offering the concrete connection paths as equal cards turns the dead end into a choice of next steps.

Apply
Skins & how to apply them

A skin is the full set of visual tokens — color, type, radius, elevation, and density — applied uniformly. Pick ONE skin per product and apply it across whichever compositions you choose: the composition is the skeleton, the skin is the paint, so any composition above renders coherently in any skin. Every frame on this page uses the Neutral column.
