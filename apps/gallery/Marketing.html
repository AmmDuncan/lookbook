01 — Secondary accent & gradient

The marketing-only tokens #secondary

Two new tokens added to the contract: --accent-secondary and --accent-gradient. They live ONLY on heroes, CTA banners, and signature surfaces — never on cards, atoms, status, or in-product UI.

--accent in-product · buttons · links
--accent-secondary hero only
--accent-gradient hero · CTA banner · signature
--accent-gradient-soft tinted hero backgrounds
Allowed on

Hero backgrounds (low-key tint or sharp band). CTA banners that need to break the page rhythm. The single signature surface per project. Brand mark in the footer.

Never on

Buttons (use solid --accent). Cards, badges, alerts, inputs, focus rings. Charts (use the chart palette). Any in-product surface. A gradient button is the fastest way to make a system look generic.

Pick a hue that pairs.
The default secondary is a warm tone that pairs with the cool blue accent — but feel free to retune it per skin. Aim for ~120° hue rotation from the accent.

08 — Signature moment

One signature per app #signature

Pick one distinctive, branded touch per project. Not three. Not a sprinkle. One.

The system above is intentionally restrained — that's what makes the signature moment legible. If everything is special, nothing is. Pick the spot the user will remember (the empty state, the loading moment, the hero, an unexpected hover) and put real craft there. Everywhere else, ship the defaults.

The rule
One signature per project. If a second moment wants in, ask: does this earn its weight, or am I sprinkling creativity?

Three examples — pick one shape per app

Example A

Custom empty-state illustration

A geometric scene unique to the brand. Shows up where the app is empty by design — first project, first invite, first export.

Example B

Branded loading animation

A small custom spinner that uses the gradient. Replaces the default .spinner on the splash and first sync — only there.

Example C

Unexpected hover reveal

A surprise on the hero card — a parallax tilt, a shine sweep, a gradient that follows the cursor. One element, one motion. Disabled under reduced-motion.
