03 / Setup

From zero to searching in four minutes

One SDK, one environment variable, no infrastructure to run.

01

Install the SDK

One package. Auto-instruments your HTTP servers, ORMs, and queues out of the box — no manual spans.

$npm install @sift/sdk
02

Set your ingest key

One environment variable. Sift's SDK reads it automatically — nothing else to configure for most stacks.

$ export SIFT_INGEST_KEY=sk_live_…
03

Ship structured logs

Use your existing logger — pino, winston, zerolog, logrus. Sift parses structured JSON automatically and indexes every field.

1import { logger } from '@sift/sdk'
2 
3logger.info({
4  event: 'charge.created',
5  amount: 4900, currency: 'usd'
6})
