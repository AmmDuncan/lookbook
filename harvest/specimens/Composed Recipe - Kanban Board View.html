Composed Recipe · Kanban / board view · one skin, five compositions

Same skin. Five ways to run a board.

One sprint board — the same tasks across To do / In progress / Review / Done — composed five ways. Every frame wears the same neutral skin: off-white page, white cards with hairline borders, slightly-rounded corners, one restrained blue accent, system sans with tabular figures. What changes is purely composition and interaction. The skin is the paint, the composition is the skeleton.

Composition 1
Classic board

PULLS — horizontal columns (To do / In progress / Review / Done) with WIP counts in headers + cards (title, tag chip, avatar, due date) + add-card affordance · one card shown mid-drag with a drop-placeholder gap in the target column.  WHY — the canonical kanban: columns make status spatial, and drag-to-move is the most direct way to advance work.

Composition 2
Swimlanes

PULLS — the same columns split into horizontal swimlanes (by priority) so each card sits at a lane × column intersection.  WHY — when one axis isn't enough: lanes add a second dimension (owner, priority, epic) so you can read both “what stage” and “whose / how urgent” without filtering.

Composition 3
Compact + collapsed columns

PULLS — a dense board where two columns are collapsed to vertical strips showing only title + count, while the active columns stay dense.  WHY — for boards with many columns or stages: collapsing the ones you're not working in reclaims horizontal space so the active flow gets the room.

Composition 4
Board + detail drawer

PULLS — the board with a right-side detail drawer open for a selected card (title, description, checklist, comments) while the board stays visible behind.  WHY — cards hold more than fits on their face; a drawer lets you open one in depth without losing the board's context the way a full-page route would.

Skins & how to apply them

A skin is the full set of visual tokens — color, type, radius, elevation, and density — applied uniformly. Pick ONE skin per product and apply it across whichever compositions you choose: the composition is the skeleton, the skin is the paint, so any composition above renders coherently in any skin. Every frame on this page uses the Neutral column.
