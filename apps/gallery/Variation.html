Lookbook · Chapter 16

Variation.

A consistent system + Personality dials + one Marketing signature gets you 90% of the way. The last 10% — the thing that makes this client's site memorable instead of competent — is a deliberate move. This chapter is the catalog: twelve composition plays, with one rule about how to use them.

01 — The rule

One move per project #rule

The system is the foundation. The Personality dials adjust the register. The signature is the one thing the visitor remembers ten minutes after closing the tab. Two signatures cancel each other out — and now the site has a costume problem.

Foundation
The system

Atoms, molecules, organisms. The infrastructure. Identical across every project.

Adjustment
Personality dials

Color, type pair, radius, density, motion, pattern intensity. Set per project from the Approach mapping table.

Signature
One move

One play from the catalog below. The thing that makes the visitor say "huh." Used once, well — never four times, defensively.

The signature isn't decoration. It's the moment of conviction that tells the visitor a designer was in the room.
02 — The catalog

Twelve composition moves #catalog

Each is a CSS-only intervention — no extra libraries, no fancy build step. Pick one. Apply it deliberately to the hero, the section break, or the lockup. Then leave the rest of the system alone.

01 — Oversized display

Type as the centerpiece

Use when the headline IS the design. 80–140px display, tracked tight, one word doing the work.

Avoid when the headline is longer than three words — the move dies at line two.

05 — Marquee band

A statement on rails

Use as a section break between hero and features. Pin a slogan, a value, or rotating customer logos.

Avoid autoplaying without a reduced-motion fallback. And never put critical info on the marquee.

Type peaks at the fold

07 — Edge anchor

A label welded to the viewport edge

Use a thin strip pinned to the viewport edge — vertical type, accent color, runs the full height. Editorial register.

Avoid in dense product UI — the strip eats horizontal space that pages need.

08 — Sticky reveal

Two columns, one fixed

Use for product walkthroughs: pin a visual on one side, scroll a list of steps on the other. Position-sticky carries it.

Avoid on mobile without a fallback — sticky reveal collapses to a normal stack at narrow widths.

09 — Off-grid placement

One card breaks the grid

Use a strict grid; let exactly one element sit a few columns off or rotated 2°. Reads as deliberate, not broken.

Avoid rotating multiple things — it stops being a wink and becomes a costume.

10 — Hand-drawn accent

A wobble in the geometry

Use a single hand-drawn underline (or circle, or arrow) under one word in the hero. SVG, accent color, 60–70% opacity.

Avoid using on more than one word per page. The marker becomes wallpaper.

11 — Oversized numerals

Numbers as the typography

Use on social-proof and case-study sections. 80–120px figures, tabular numerals, top-anchored 2px rule above each.

Avoid using vanity numbers ("4 founders, 7 cups of coffee"). Numbers earn the size or they don't.

12 — Rotated margin label

The eyebrow lives in the gutter

Use a section number or category tag rotated 90° in the left margin. Editorial; signals magazine layout.

Avoid in dense product UI or on mobile — the rotated text collapses awkwardly.

04 — Discipline

Don't over-do it #discipline

More moves do not equal more design. They equal more noise. The discipline that makes variation work is what you don't add.

One signature per projectnever two
Pick the wildcard in the Approach kickoff doc. Use it on the hero, the about-page header, and one section break. Three appearances, max.
Don't apply a different move on every section. The first one stops being a signature.
The system is the floorthe move sits on top
Build the page with the standard components first. Add the move last. If you can remove the move and the page still works, you got the order right.
Don't design the move first and pour content into it. The result is a costume looking for a body.
Moves use existing tokensno new colors · no new sizes
Express the move using the existing accent, font-display, and motion easings. The move is a composition decision, not a token swap.
Don't introduce a one-off color or font for the move. You're back to a costume.
Reduced-motion fallbackevery animated move
Define the final state and skip-to-it under prefers-reduced-motion. The visual still works; the kinetic does not.
Don't ship marquees, scroll-driven type, or sticky reveals without the static fallback.
Mobile dignityevery move
Decide what the move becomes at < 640px. Many — edge anchor, rotated label, sticky reveal — collapse to the standard layout cleanly.
Don't let a desktop signature trash the mobile experience. The mobile fallback is part of the move.

The signature is the proof a designer was here.

Every chapter before this builds the floor under your work. This one is the small, deliberate gesture on top — the move that turns a competent site into a recognized one. Pick well, use once, leave the rest of the system alone.
