Composed Recipe · Profile / public page · one skin, five compositions

Same skin. Five ways to be a profile.

One person — Mara Reyes, product designer — presented five ways. Every frame wears the same neutral skin: off-white page, white surfaces with hairline borders, slightly-rounded corners, one restrained blue accent, system sans with tabular figures. Avatars and covers use the hairline-striped placeholder. What changes is purely composition and interaction.

Composition 1
Header + stats

PULLS — a full-width cover band + overlapping avatar + name/handle/bio + a stat row (followers / following / posts, tabular) + Follow/Message actions; content cards below.  WHY — the social default: the cover and overlapping avatar create identity at a glance, and the stat row plus primary action answer “who is this, and what can I do.”

Composition 2
Tabbed content

PULLS — a profile header + horizontal tabs (Overview / Posts / About / Activity) + the active tab's content.  WHY — for profiles with depth: tabs keep a rich, multi-faceted page navigable so the first view stays calm while everything remains one click away.

Composition 3
Sidebar bio + main

PULLS — a left sidebar (avatar, bio, details list: location / role / links) + a right main column (a feed/list of the person's items).  WHY — when the work matters more than the persona: a fixed identity sidebar frees the main column to lead with output, the way a portfolio or author page does.

Composition 5
Edit-mode profile

PULLS — the editable version: inline-editable fields (name, bio), an avatar-upload affordance, a visibility toggle (visible sliding thumb), and a sticky Save bar.  WHY — editing your own profile is a distinct mode: in-place fields and an obvious upload target keep it direct, while the sticky bar makes saving unmissable.

Skins & how to apply them

A skin is the full set of visual tokens — color, type, radius, elevation, and density — applied uniformly. Pick ONE skin per product and apply it across whichever compositions you choose: the composition is the skeleton, the skin is the paint, so any composition above renders coherently in any skin. Every frame on this page uses the Neutral column.
